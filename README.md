# 單字日課 v3.4｜手機優先・情境例句・浮動輕量組

版本日期：2026-11-11。會考日期：**2027/05/15–16**。本版本保留前版瀏覽器學習紀錄欄位，新增題型介面、字庫例句與彈性配額。

## 先試用（不用設定雲端）

解壓縮完整 ZIP，**直接打開 `index.html`**，即可使用本機版：

- 2,005 條課綱詞目全部已有情境例句；題目**一出現就有例句**。除英翻中外，中翻英、拼寫、克漏字會先遮住句中的答案，以免洩題。
- 每日新字不從 A 排到 Z；依參考主題輪替，並穿插到期複習。字庫總覽可選 12 個生活主題，這是為學習重新整理的分類，**不是教育部表三原始分類逐條複製**。
- 輕量組每天浮動：`尚未首次答對的官方詞目 ÷ 從今天到 2027/05/14（含）的剩餘天數`，無條件進位；**到期複習數另加在當日任務中**，且以可持續量安排。即使很多天沒練，浮動的新字目標也會增加。
- 標準組每天 30 個詞目、考前衝刺組每天 50 個詞目，包含複習及新字。當日開始任務後，配額鎖定，改設定從次日起作用。
- 答對後短暫顯示成功即自動前往下一題，無須再按「下一題」；答錯會顯示正確意思及完整例句，須手動繼續且該詞稍後重練。
- 練習完成日出現在學習月曆；資料保存在本機瀏覽器，也可在帳號設定匯出／匯入備份。

### 網站正式部署

請將以下檔案放在 GitHub Pages 網站的**同一資料夾**（可整包覆蓋之前的單字 App 版本）。不要只上傳 `index.html`：

```
index.html
app.js
styles.css
word-data-full.json
word-data-full.js
config.js
sw.js
manifest.webmanifest
```

如已開啟舊版網站，重新整理仍顯示舊介面時，請先關掉所有該網站頁面後再開啟，或清除該網站的快取。**切勿為了解決快取而清除學習紀錄**；更新前可先匯出本機備份。

## 帳號與導師查核（需要 Supabase）

本機試用**不會**讓導師遠端看到昨日完成紀錄。要使用學生帳號、跨裝置學習、學生班級加入與教師查核，請依下列步驟設定：

### 從未建立 Supabase 專案

1. 建立 Supabase 專案，確認學校是否允許學生使用第三方雲端服務；測試時先使用假座號／測試信箱。
2. 在 Supabase SQL Editor 執行 `setup_supabase.sql`。
3. 在 `config.js` 填入 Supabase Project URL 和 **publishable/anon key**；**不可**使用 secret/service-role key。
4. 將改好的 `config.js` 與所有網站檔案上傳 GitHub Pages；於 Supabase Authentication 設定 Email 登入／確認信、Site URL 和 Redirect URLs。
5. 教師先於網站註冊、驗證 Email，再由專案管理者於 SQL Editor 將教師帳號加到 `public.teachers`，SQL 示例如下：

   ```sql
   insert into public.teachers(user_id)
   select id from auth.users where email = 'TEACHER_EMAIL@example.com'
   on conflict do nothing;
   ```

6. 教師登入並建立班級，學生登入、輸入班級碼與座號，教師核准加入，隔天教師可從「導師查核」看前一天的完成紀錄及匯出 CSV。

### 已經使用 v3.2／v3.3 的 Supabase

**先備份資料庫**，只需要在 Supabase SQL Editor **執行一次 `upgrade_v3_4_supabase.sql`**，讓資料庫允許動態的輕量組每日數量。**不要重新執行整份初次建置的 `setup_supabase.sql`。** 本次升級只調整每日配額限制與開始當日任務的函式，設計上會保留原有學生與班級資料。

如未執行升級 SQL，使用浮動輕量組時可能遇到「配額僅限 15、30、50」的雲端錯誤，且導師無法可靠取得完成紀錄。

### 導師抵免小日記的運作原則

- 以**雲端「昨日已完成」**為依據，而不是學生手機截圖。
- 學生需登入自己的帳號、加入已核准班級、在當日完成系統鎖定的配額，並成功將紀錄送達雲端。
- 若學生當天離線完成，**本機完成不等於雲端完成**；應提供合理的申訴或補登管道。
- 目前的題目與完成事件由前端操作，雖然伺服器驗證詞目 ID、單日不同詞目數與時間，但不是不可作弊的正式測驗。**雲端雙帳號完整驗收仍未進行。**

## 教學研究依據（提供教師參考，不顯示在學生介面）

- **同類詞的干擾 vs. 情境串連**：Tinkham (1993), *System*, 21(3), 371–380；Tinkham (1997), *Second Language Research*, 13(2), 138–163。近義詞一次大量一起記可能干擾，情境相關而詞性不同的詞則較有利。本 App 採主題輪替及不同詞類混合，不強迫 A～Z。
- **雙向提取**：Bernardi et al. (2024), *Memory*, 32(9), 1235–1246, DOI 10.1080/09658211.2024.2397043；接受性提取與產出性提取效果只能部分互通。因此初學先英翻中、熟悉後再加入中翻英與拼寫。
- **間隔與克漏字**：*The Modern Language Journal* (2023), DOI 10.1111/modl.12879；間隔練習對填空與單字卡都有效。本 App 仍保留克漏字，但隱藏目標詞避免例句洩題。
