# 單字日課 v3.7｜每日任務首頁整合＋題型自主練習

這個版本改為**學生個人學習 App**。保留 2,005 詞目、情境例句、主題學習、輕量浮動、標準 30、衝刺 50、記憶排程、自由加練／繼續學新字、學習月曆；新增**例句與單字朗讀、安裝到 iOS/Android 主畫面、完成卡截圖**。老師不需要建立班級或後台帳號。

**重要**：字庫已完成「附錄五詞目與用字範圍」程式檢查，但尚未完成全部中文釋義與例句的人工語義、文法審核。`example_quality_review.csv` 留作後續校稿。

## A. 上傳 GitHub Pages

將下列檔案上傳 GitHub 專案首頁所在的**相同目錄**，不要把 ZIP 或上層資料夾直接上傳：

```text
index.html
app.js
styles.css
word-data-full.json
word-data-full.js
sw.js
manifest.webmanifest
config.js（只有在首次部署或準備更新雲端設定時才需覆蓋）
icons/icon-192.png
icons/icon-512.png
icons/icon-512-maskable.png
icons/apple-touch-icon.png
```

`icons` 必須保留資料夾層級；`setup_cloud_backup.sql`、CSV、README 不是網站運作必要檔案，不必上傳到公開 GitHub。

**已在 `config.js` 寫入 Supabase URL / anon key 的用戶**：不要用 ZIP 附的空白 `config.js` 覆蓋原設定。原有帳號的登入與備份才不會突然消失。

更新後打開你原來的 GitHub Pages URL 即可。網站已新增 v3.7 Service Worker，首次更新建議關閉舊網頁、重新打開；若仍看到舊版，再重新整理。不需要清掉瀏覽器儲存空間，**清除網站資料可能刪掉尚未備份的學習進度**。

## B. 加到手機主畫面（不用上架商店）

- **iPhone / iPad**：用 Safari 開啟 App 網址 → 分享（Share）→「加入主畫面」→ 若有「作為網頁 App 開啟」請啟用 →「加入」。
- **Android**：用 Chrome 開啟 App 網址 → 右上方選單（⋮）→「安裝或建立捷徑」→「安裝」（不同版本可能顯示「安裝應用程式」或「加入主畫面」）。
- App 的「我的設定」內也有「加入主畫面」提示。如果瀏覽器提供原生安裝提示，Android 可直接在 App 內呼叫。
- PWA 使用相同網站更新：不是 App Store / Google Play 原生應用。它在各平台顯示及離線支援取決於瀏覽器與裝置。

## C. 英文朗讀

- 題目卡有「🔊 聽例句」，單字卡有「🔈 單字發音」，主題字庫的每一個詞目也可點擊聽單字及完整例句。
- 在**英翻中**題，完整例句、單字可一開始朗讀；在中翻英／克漏字／拼字題，例句中的答案以空白遮住，朗讀也不會讀出答案，直到學生作答完畢才可以聽完整句子與正確單字。
- 設定頁可調朗讀速度。使用瀏覽器 `speechSynthesis` / 手機系統的英文語音，**沒有預先錄製 2,005 段音檔**。音質與是否能在離線狀態發音，取決於裝置已安裝的英文語音；按喇叭才開始讀，不會自動出聲。

## D. 註冊帳號，只為保存個人進度（需要 Supabase）

可先純本機試用；**本機試用不等於帳號備份**。要在換手機後恢復紀錄：

1. 建立一個 Supabase 專案，先評估學生使用外部雲端帳號是否符合學校政策。建議採最低資料蒐集：電子郵件／匿名顯示名稱、單字學習紀錄。不要要求真名或學生證號。
2. 在該專案 **SQL Editor** 執行 `setup_cloud_backup.sql`，會建立（或沿用）`profiles` 與 `student_progress`，並設定**只能由本人讀寫**的 RLS 權限。對已使用 v3.2-v3.5 的專案，SQL 不會刪除既有進度。新版本**不需要**原來的教師表、班級或每日完成 RPC。
3. Supabase Authentication 開啟 Email 登入；確認 Email 驗證與 Site URL / Redirect URLs 設好為實際 GitHub Pages 網址。
4. 在網站的 `config.js` 寫入：

   ```js
   window.VOCAB_CLOUD_CONFIG = {
     url: 'https://你的專案.supabase.co',
     anonKey: '你的 publishable / anon key'
   };
   ```

   **絕對不要貼 secret、service_role key 或個人密碼進網頁檔案。**
5. 上傳更新後的網站；註冊、驗證信箱、登入，在帳號頁點「立即備份」，看到「☁ 已備份」才算備份成功。用**第二台測試裝置登入同一個測試帳號**，確認進度還原後再正式發給學生。
6. 同一裝置第一次登入時，如果原本有訪客練習紀錄，App 會詢問是否要併入帳號；共用裝置請選「取消」，不要混入別人的進度。
7. iOS 主畫面 Web App 有機會與 Safari 使用不同的本機儲存環境；安裝後請**再次登入同一帳號並確認雲端進度已恢復**。避免只依賴安裝前的本機紀錄。

**備份限制：** 離線先記錄在本機，網路恢復後再嘗試上傳。裝置同時登入並「同時」修改同一個詞目的進度仍可能出現同步競爭；上線前應進行兩裝置試用，且定期匯出 JSON 備份。帳號不是零風險保證，需收到雲端完成狀態才算成功備份。

## E. 聯絡簿小日記抵免（改成截圖）

學生完成今日任務後，頁面顯示完成卡：顯示名稱、台灣日期與完成配額。若當天忘記截圖，也可從「學習月曆」點選已完成日期，重新開啟對應完成卡。學生使用手機**截圖此畫面**再傳給老師即可。不再需要建立導師後台、班級碼或核准流程。截圖仍有被更改的可能，應作為信任與鼓勵性回報，**不視為防作弊憑證**。加練不會代替隔天的每日任務。

## F. 測試與重要限制

- 靜態頁面、PWA manifest、icon 與 Service Worker 語法可先在開發環境驗證；iOS / Android 必須用實體手機從 HTTPS 網站安裝並實際測試語音。電腦瀏覽器無法等同於真實兩平台驗收。
- 語音是裝置本地／瀏覽器聲音合成，英文口音與聲音可能不同。
- 電子郵件註冊、雲端同步需開啟 Supabase，不能只上傳 GitHub Pages 就聲稱可跨機保存。
- 首輪與「已熟練」是不同概念；輕量組以未首次答對詞目與剩餘天數重新計算，不代表所有字已牢記。


## G. v3.7 首頁與自主練習更新

- **首頁合併**：將今日任務和會考倒數放進同一張原本的漸層色卡，進度、今日完成狀態與作答按鈕統一呈現。
- **每日學習量**：仍維持輕量浮動、標準30、衝刺50，首輪預估日期整合到這一區底部。
- **獨立色彩**：首次答對／待複習／已熟練改用淡紫、淡粉、奶油黃，避免與藍綠橘的每日配額混淆。
- **自由學習**：原「預習明天」更名為「繼續學新字」，每輪完成後還能繼續下一輪，直到新字學完；但只記錄實際完成的今日任務為當天完成卡。
- **自主練習**：首頁新增四個入口：綜合練習、英翻中、中翻英、克漏字，每輪10個詞目，可在當日任務前或後使用。中翻英為四選一英文答案（非直接拼字）；克漏字顯示挖空的例句與四個英文選項。自主練習不代替每日完成卡。
- **作答整理**：四選一不顯示1234編號；單字發音按鈕移至例句發音按鈕上方，且在中翻英／克漏字／拼字題完成作答後才露出，以免先聽到答案。

**升級注意**：這版沿用 v3.6 的學習紀錄結構與 Supabase 備份資料表，無需新 SQL。請只覆蓋網站程式檔，保留現有 `config.js` 以及 Supabase 設定。更新 PWA 後請關閉舊版分頁並重新開啟以讓快取生效。
